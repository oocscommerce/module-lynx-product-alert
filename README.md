# Lynx Product Alert

`oocscommerce/module-lynx-product-alert`

Price and stock alerts from Magento_ProductAlert on the Lynx storefront.

## Features

- Price and stock alert links on the product page
- The stock alert unsubscribe page
- Disable it together with Magento_ProductAlert to drop product alerts

## Installation

Part of [Lynx](https://docs.oocscommerce.com/lynx/), installed with the metapackage:

```bash
composer require oocscommerce/magento2-lynx-community
```

See [Installation](https://docs.oocscommerce.com/lynx/developer/installation) for the full setup.
